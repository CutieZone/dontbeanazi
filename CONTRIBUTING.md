# Contributing to Don't Be A Nazi

Thanks for contributing to the documentation of authoritarian patterns.

## Quick Start

1. Fork the repository
2. Create a branch: `git checkout -b entry/your-entry-name`
3. Add your entry using the [template](./ENTRY_TEMPLATE.md)
4. Ensure all sources are cited and archived
5. Submit a Pull Request

## Full Guidelines

See the [Contribute page](https://dontbeanazi.cutie.zone/contribute/) for complete guidelines.

## Requirements

- Minimum 3 reliable sources
- Archive.org links for all sources
- Follow the entry template
- Neutral, factual language
- Clear documentation of authoritarian patterns

## Categories

- `surveillance/` - Privacy violations, encryption back-doors
- `atrocities/` - Genocides, mass violence (ongoing and historical)
- `targeting-marginalized/` - Laws targeting specific groups
- `corporate/` - Corporate harm, environmental destruction
- `thought-control/` - Speech restrictions, propaganda

## Entry Template

Copy `ENTRY_TEMPLATE.md` and fill it out completely. Every section is required.

## Questions?

- Check existing entries for examples
- Open a GitHub Discussion
- See the [About page](https://dontbeanazi.cutie.zone/about/)

## Code of Conduct

- Be honest - source everything
- Be respectful - of victims and truth
- Be focused - document authoritarian patterns
- Don't defend atrocities or act in bad faith
